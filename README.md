# Word 单行写作工具

在 Microsoft Word 窗口底部显示一个独立的单行写作区域，上方继续显示原文档。小说以单独的 TXT 文件自动保存，可以通过上下键回看、修改前文。

## 功能

- 一次显示一行，长行水平滚动。
- 宋体 10.5 磅，纯白无边框；输入区域左右各内缩 8 像素，留出 Word 纸张边线。
- ↑ / ↓ 切换前后行，并直接编辑。
- Enter 在光标处换行。
- 自动保存草稿，重新启动恢复最后一行。
- 保存时保留上一次保存前的备份；检测到草稿被其他程序修改后停止覆盖保存。
- 切换到其他应用时隐藏输入区域。

## 下载与使用


1. 打开一个 Word 文档。
2. 双击「单行写作.exe」，点击「开始写作」。
3. 点击底部输入区域，开始输入小说。

| 按键 | 功能 |
| --- | --- |
| Ctrl + Alt + Shift + N | 显示 / 收起输入区域 |
| ↑ / ↓ | 回看、编辑前一行 / 后一行 |
| Enter | 在光标处换行 |
| Esc | 收起输入区域，返回 Word |

主快捷键被占用时，改用 Ctrl + Alt + Shift + F10；实际快捷键显示在启动窗口与托盘菜单中。也可以双击托盘图标显示 / 收起。

中文输入法显示候选时，上下键交给输入法选择候选。候选关闭后，再使用上下键回看前文。

## 草稿保存位置

程序所在文件夹 → **我的小说 → 小说草稿.txt**。

停止输入约 0.65 秒后自动保存；换行、回看、收起和正常退出时也会尝试保存。`小说草稿.txt.bak` 是上一次保存前的备份，不是长期版本历史。强制结束或断电前最后不足 0.65 秒的输入可能尚未保存。

小说单独保存，原 Word 文档保持原样。运行时点击 Word 原文档，输入会进入 Word；继续写小说时需要点击底部写作区域。

若需用其他软件修改小说全文，请先退出工具。更新程序时先退出旧版，替换 exe，并保留「我的小说」文件夹。

详细说明见 [使用说明](使用说明.md)。

## 运行环境

- Windows 桌面。
- Microsoft Word 桌面版。
- .NET Framework 4.x，包含 Windows Forms 与 WPF UI Automation 组件。

建议使用 Word 的「页面视图」。未取得可见纸张边界时，工具使用居中的较窄输入区域。

## 从源码构建

源码位于 `src/WordLine.cs`。Windows 中的 .NET Framework C# 编译器可通过以下脚本构建程序：

```powershell
.\build.ps1
```

输出文件为 `dist/单行写作.exe`。工具不需要 Word 宏。
